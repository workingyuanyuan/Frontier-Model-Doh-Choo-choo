# 來源刷新審核報告 — 2026-08-20

## 範圍

本次刷新修正 C7 的 Artificial Analysis 擷取。它恢復 AA 官方發布的
Artificial Analysis Intelligence Index，並將其保存為僅供顯示的證據；同時從實際承載
該欄位的模型詳情 payload 讀取正規化 GDPval-AA。所有缺失的分數、成本、effort 或
identity 均未推估。

前一份已審核產品資料為 `HEAD` 版本。D4 工作目錄建置另列，因為在 C7 開始前，
其 nullable 成本保存修正已經改變待審的 `current.json`。

## 主畫面進出

無。主畫面仍維持相同的 12 個模型列。C7 補齊帶成本 profile 的 GDPval-AA，但
`gdpval-aa` 不在 14 項 display set 內，因此本次刷新會改變分數，卻不會改變主畫面
資格。

因為刷新的 AA payload 不再提供下列配置，7 個僅供開發使用的 profile 已消失：
Claude Sonnet 4.6 non-reasoning、Gemini 3.5 Flash low 與 medium、GPT-5.3 Codex
xhigh、Grok 4.3 low、MiMo V2.5 Pro non-reasoning，以及 GLM-5.2 non-reasoning。
它們的 canonical models 仍保留在 frontier set；沒有任何主畫面模型退出。
