## 4. 本次變更與代理判斷

### 4.1 前沿資格規則（使用者決定方向，細節由代理具體化）

依 AA 名次逐一檢查，取前十個合格模型作為拉桿範圍（[前沿政策](../FRONTIER_POLICY.md#模型資格)）：

- **可計分**：有正規化分數、已分類、不是 `comparisonOnly`、沒有被品質政策排除。
- **不計入**：AA 本身（它是排名依據）；廠商發布頁（`VENDOR` 角色，自報成績）。
- **組織**：Surge 的七個排行榜算一個組織，其他來源各算一個。
- **門檻 2**：用目前資料檢查，門檻 1 會讓 Kimi K3.1 Pro（只有 LiveBench）進入第 4 名，與第 3 名的 Muse Wonder Full 沒有任何 AA 以外的共同測試，預設集合會只剩 AA 的測試；門檻 2 正好排除這兩個模型，前十個合格模型都有 3～8 個組織。

本次被略過的模型：

| ------: | ---------------- | ----: | ------------------- |
|       3 | Muse Wonder Full | 55.80 | Vals                |

被略過的模型仍可用 Search Models 選取。若有未解析身分的 AA 分數不低於第十個合格模型，或合格模型不足十個，產品建置會停止。

### 4.2 其他決定

- **Kimi K3.1 Pro 建立為獨立模型**（`moonshot-kimi-k3-1-pro`）。依據是[官方公告](https://www.kimi.com/en/blog/kimi-k3-1-pro)：「a post-trained version of Kimi K3」。別名 `kimi-k3-1-pro`（AA）、`kimi-k3.1-pro`（LiveBench）；發布日期取 AA 與 Epoch 記錄的 2026-10-23。「Kimi K3.1 Pro Highspeed」是另一個產品，沒有併入。
- **Vals Finance Index、Legal Index 歸為綜合指數。** 兩者都是既有測試的加權聚合（Finance Index：Finance Agent、EMB、Tax Agent Bench；Legal Index：Legal Research Bench、HLAB、Tax Agent Bench），計分會重複計入成分測試。原本因「尚未核准」被排除，現在改以「綜合指數」原因排除，結果相同。
- **AA API 交叉驗證已執行**（使用者補上的金鑰有效）。比對 256 列、1,379 個值：677 個是 API 取到小數三位的差，真正的差異為 0。
