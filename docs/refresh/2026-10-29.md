## 3. 計分決定與依據

- **Terminal-Bench 4.0**：新 ID `terminal-bench-4-0`，維度同 `terminal-bench-2-1`。它是另一代測試（66 題、重新校準），不是取代 2.1 的版本，因此兩者都計分。
  - **AA 來源**（`terminalBench40`）：AA 頁面明載「We run all 66 Terminal-Bench 4.0 tasks with the mini-swe-agent harness and report pass@1 averaged over three repeats per task」，已記錄 harness 與 attempts。
  - **Vals 來源**（`terminal-bench-4`）：加入 Vals 的核准清單。
- **AutomationBench-AA 不計分**：AA 頁面明載「Unlike Zapier's own hosted AutomationBench leaderboard, which reports the percentage of tasks completed fully, AutomationBench-AA uses ... the average share of each task's objectives」。這與主辦方 Zapier 榜的嚴格任務完成率是不同指標，已登記在 `source-monitoring.json` 的 `deferred`。

## 4. Gemini 4 Carbon

- **AA 分數**：AA Intelligence Index v5 為 **59.43**，排名第 1，高於 Opus 5.5 的 58.41。
- **來源成績**：AA 與 Vals 都已有成績。Vals 有十榜，其中 HLAB、Legal Research、VibeCode 可計分。
- **建置停止的原因**：原本沒有對應的模型身分。前沿政策規定，未解析的 AA 分數若在前十內，產品建置須停止。
- **官方證據**：[Google 官方公告](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-carbon/)（2026-10-28）的名稱為「Gemini 4 Carbon」，並寫明「Carbon ranks #1 on the recently updated v5.0 of Artificial Analysis Intelligence Index at 59」，與 AA 資料一致。
- **新增的身分**：`google-gemini-4-carbon`，別名 `gemini-4-carbon`、`google/gemini-4-carbon`。AA 名稱明示 High，Vals 也對應到 high。
- **新增後的結果**：Carbon 目前只有 Vals 一個獨立組織的成績，依前沿政策（至少 2 個組織）被跳過，和 Muse Wonder Full 相同；它仍可在 Search Models 中選取。等 LiveBench 等其他來源評測它之後，就會自動進入前沿，屆時名次會明顯變動。
- **開放範圍**：官方說明目前只開放給部分資安防禦者，開發者與一般使用者稍後才能使用。
