## 匯入修正

1. AA 同一 Opus 5.5 的 max row 日期為9/22，其餘四檔為9/17。原全模型最新日期篩選誤刪四檔，已限制為有審核過日期版本 alias 的模型；DeepSeek 舊 build 排除測試仍通過。
2. AA detail 頁明示的 effort 選單網址額外擷取一層，本次補抓42頁，保存每檔 provenance。
3. LiveBench 母體按來源 bundle 宣告的 variants 分組比對，保留 CSV 各檔位。
4. LiveBench 成本由固定名單加上同分數匯入使用的 catalog resolver，補齊可精確辨識的成本；總成本數增加含既有模型映射恢復。
5. E2E 依當前成本資料選擇可驗證檔位，不再假設 Opus 5 必有 AA 覆蓋；圖表點新增 profile data attribute，使縮軸測試能保留單一最低成本檔位。
