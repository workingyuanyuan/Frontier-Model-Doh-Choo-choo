## 4. 本次由代理依證據決定的事項

### 4.1 LiveBench 2.0 整合（使用者決定整合，維度由代理判定）

LiveBench 自 2026-10-14 起改版為 2.0（`data/20261014/`），1.0 以凍結的歷史 release 保留於 `./v1/`。處理方式：

- **2.0 的七個 suite 全部納入**，維度依方法論頁「評分對象」判定（Codex Astra 審視後，把 Long Agentic 由代理改為程式）：

  | Suite         | Benchmark ID              | 主維度 | 依據                                                       |
  | ------------- | ------------------------- | ------ | ---------------------------------------------------------- |
  | Long Agentic  | `livebench-long-agentic`  | 程式   | 18 題中 15 題建置、維護或優化軟體，以腳本對照隱藏測試評分  |
  | Coding        | `livebench-coding`        | 程式   | 修正真實 PR 的 bug，以隱藏測試評分                         |
  | Reasoning     | `livebench-reasoning`     | 推理   | 無工具的邏輯、空間與心智理論題；沿用既有 ID，改為 2.0 版本 |
  | Data Analysis | `livebench-data-analysis` | 理解   | 給定小表格的問答，無工具                                   |
  | Browser       | `livebench-browser`       | 代理   | 透過截圖操作網頁應用，評分應用程式的結果資料               |
  | Research      | `livebench-research`      | 代理   | 研究並撰寫附來源的報告，依 rubric 評分                     |
  | Design        | `livebench-design`        | 代理   | 依需求產出 Word、PDF、簡報，渲染後檢查                     |

- **effort** 取自 2.0 模型登錄（方法論頁說明各模型以最高支援檔位執行）。
- **1.0 Reasoning** 有 2.0 的新版本，71 列全部改為 EXCLUDED，作為證據保留。
- **1.0 Language、Instruction Following、Mathematics** 在 2.0 已被移除，依「移除的保留」原則，沿用 1.0 歷史 release 的成績。重新擷取時，既有列不得消失或改分；1.0 release 後來新增的模型列（Claude Haiku 5.5、Mistral Large 4、Muse Wonder 1.0 等）照常納入。
- **成本**：2.0 依方法論以「各 suite 總成本 ÷ 總任務數」為每個模型產生一筆任務成本；1.0 的「每次成功任務成本」改為 EXCLUDED，避免與 2.0 的數字混算（Codex Sol 審查時發現）。
- **集中度**：七個 suite 中有五個屬於代理或程式維度。目前 2.0 suite 只進入前 2 名集合，不會壓過其他來源；若日後在預設集合中主導某個維度，是否設上限需要使用者決定。

### 4.2 其他決定

- **Muse Wonder 拆成兩個模型。** 依據是 [Meta 官方公告](https://research.meta.ai/blog/muse-wonder)：「introduce the Muse Wonder series with Muse Wonder and Muse Wonder Full」，並以「both models」稱呼兩者（2026-10-12 發布）。LiveBench 與 Surge 的「Muse Wonder 1.0」對應到 Muse Wonder：公告寫明 Muse Wonder 透過 Meta Model API 提供，Muse Wonder Full 只給 Muse Code 訂閱者，而這兩個榜單都是透過 API 測試。
- **AA GDPval 改由 Elo 換算。** AA 比較列移除了 `gdpvalNormalized`，但 GDPval-AA 沒有下架，仍公開 Elo（`gdpval`）。[方法論頁](https://artificialanalysis.ai/methodology/intelligence-benchmarking) 公布的換算式是 `clamp((Elo − 500) / 2000)`，在 10-04 擷取的 282 組 Elo 與正規化值上全部吻合。現在依此式由現行 Elo 換算，`gdpval-aa` 因此回到所有集合（195 列）。
- **Zapier 暫定成績照常採用。** § 符號改為標在 Claude Haiku 5.5 的五列模型名稱後，註腳為「Initial results based on the launch version of Haiku 5.5. Scores will be updated after an updated Haiku 5.5 release is evaluated.」。成績照常採用，註腳原文保留在出處欄位。Haiku 5.5 目前還沒有 catalog 身分，這五列不影響產品。
- **Vals Router Index。** 這個新頁面比較的是路由器、不是單一模型（資料格式為 `chart_view_*.json`），因此視為「已擷取、無模型成績」。
